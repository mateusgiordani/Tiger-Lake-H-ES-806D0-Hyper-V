BACKUP SOMENTE LEITURA - POLESTAR HM570 / THM570111

Este pacote NAO contem arquivo .bin e NAO contem startup.nsh.
Ele nao inicia gravacao automatica. O FPT deve ser comandado manualmente.

PREPARAR O PENDRIVE

1. Formate um pendrive em FAT32.
2. Copie a pasta EFI, o arquivo Fpt.efi e este texto para a raiz do pendrive.
3. Se Secure Boot estiver ativo e o pendrive nao iniciar, desative-o apenas para este teste.
4. Escolha o pendrive no menu de boot UEFI.

LOCALIZAR O PENDRIVE NO UEFI SHELL

Execute:

  map -r
  fs0:
  ls

Se Fpt.efi e LEIA-ME-BACKUP.txt nao aparecerem, tente fs1:, fs2: e assim por diante.

CRIAR DUAS LEITURAS COMPLETAS

No sistema de arquivos correto, execute:

  Fpt.efi -i
  Fpt.efi -d polestar_full_1.bin
  Fpt.efi -d polestar_full_2.bin

Nao use -F, /F, -ERASE ou qualquer comando de gravacao.

RESULTADO ESPERADO

Cada dump completo deve possuir exatamente 16777216 bytes (16 MiB).
No Windows, compare os arquivos:

  Get-FileHash .\polestar_full_1.bin -Algorithm SHA256
  Get-FileHash .\polestar_full_2.bin -Algorithm SHA256

Os dois hashes devem ser identicos.

SE O DUMP COMPLETO FOR BLOQUEADO

Anote ou fotografe a mensagem de erro. Pode-se tentar uma leitura apenas da
regiao BIOS, que nao substitui o dump completo para recuperacao:

  Fpt.efi -BIOS -D polestar_bios_region.bin

Na THM570111 analisada, essa regiao deve ter 11534336 bytes (11 MiB).

Um backup definitivo para recuperacao deve ser feito diretamente no chip SPI
com gravador externo, depois de confirmar o modelo e a tensao do chip.
